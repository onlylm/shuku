选择书目表格

支持 Excel 或 CSV，最大 5MB；表头至少包含「系统编号」「书名」或「ISBN」其中一列。

匹配顺序

  • ✓ 系统编号优先（有编号时禁止回退匹配其他书）→ 无编号才按唯一 ISBN → 文件名 → 书名+作者 → 书名精确 → 书名相似
  • ✓ 「书名 - 作者.epub」会自动拆开，和云盘上传时的解析一致
  • ✓ 相似度匹配的行默认不勾选，需要你确认后再导入
  • ✓ 默认只填补空缺字段，已有数据不会被覆盖

支持的列名

  • ✓ 中文：书名、文件名、作者、出版社、出版年份、简介、语言、格式、分类
  • ✓ 两级分类：主分类 + 子类 两列，只匹配网站已有分类或管理员保存的来源映射
  • ✓ 每本书只维护一个一级分类与至多一个二级分类，不自动创建或模糊合并分类
  • ✓ Calibre 导出：title、authors、publisher、pubdate、comments、languages、formats、isbn

Calibre 的 tags 列不会导入：里面多是「公众号：xxx」「电子书免费赠送」这类来源标记，会污染分类。要导分类请另建「分类」或「主分类/子类」列。
