# 书库

面向个人运营者的图书资源索引网站。集中管理图书资料、分类、封面和网盘分享入口，访客可以搜索图书并跳转到对应网盘。

网站不附带真实电子书、私人书库或网盘账号。域名和网站名称由部署者自行填写。

[部署教程](docs/部署说明.md) · [后台使用说明](docs/使用说明.md) · [全部文档](docs/README.md) · [已知问题与限制](docs/已知问题与使用限制.md)

## 网站功能

- 图书首页、资源列表、分类、搜索、详情页和网盘跳转。
- 后台管理图书、父子分类、分享链接、友情链接和发布状态。
- CSV / XLSX 导入预检，识别百度、夸克分享链接，提示重复与冲突。
- 链接检测、失效隐藏、替换复检，以及可选的定时巡检。
- 资源访问、跳转和无结果搜索统计。
- canonical、Book 结构化数据、robots.txt 与 sitemap.xml。
- Linux 一键部署、自动 HTTPS、数据库迁移、备份恢复和更新。
- v2 系统设置：网站名称与图标、账号安全、封面域名白名单、域名验证及管理员自主选择的正式版本更新。

仓库还包含 Windows 本地整理工具源码与网站同步接口。**桌面工具仍有上传、批处理和同步状态方面的已知问题，不作为已验收的全自动发布产品。** 网站部署不依赖该工具，可先通过后台录入资料和已有分享链接。

## 部署到 Linux

准备一台 Linux 服务器，以及已经解析到服务器的域名。需要开放 80/443 端口。

在服务器中依次执行，每次一条：

```bash
git clone https://github.com/onlylm/shuku.git ebook-site
```

```bash
cd ebook-site
```

```bash
sudo bash deploy.sh
```

按提示填写域名和网站名称，保存脚本显示的初始管理员密码。看到 HTTPS 和页面检查通过，再打开网站与 `/admin/login`。

**完整的“输入命令 → 查看提示 → 填写内容 → 确认成功”教程，见 [部署说明](docs/部署说明.md)。** 环境要求、排错、密码重置和更新都在教程中；已有项目不要重复克隆。

正式部署使用 MySQL 8.4、FastAPI、Caddy 与 Docker Compose。首次启动为空书库，不携带开发数据。

## 开始使用

1. 登录后台，确认网站名称、分类和网盘渠道。
2. 录入一本有权发布的图书，填写资料、封面和分享链接。
3. 核对资源发布状态，执行链接检测。
4. 在前台检查详情、封面、跳转和提取码，再分批录入更多资源。

“已发布”不等于一定出现在前台：还需要至少一个检测有效、允许显示且渠道启用的链接。具体操作见 [后台使用说明](docs/使用说明.md)。
