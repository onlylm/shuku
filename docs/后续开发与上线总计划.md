# 本地电子书整理软件与网站一体化：完整开发及上线计划

版本：3.0；日期：2026-08-31。本文是开发范围与验收契约，不是完成证明。

## 1. 本轮范围与位置

用户确认做**完整本地整理软件**，不采用省去整理功能的轻量版。

- 整个项目、现有网站：`D:\网盘拉新`。
- 本文：`D:\网盘拉新\docs\后续开发与上线总计划.md`。
- 本地软件源代码：`D:\网盘拉新\ebook_organizer`。
- 启动、打包和维护脚本：`D:\网盘拉新\scripts`。
- 软件使用说明：`D:\网盘拉新\docs\本地整理软件使用说明.md`。
- 源码默认工作数据：`D:\网盘拉新\runtime\organizer`；便携版默认当前用户 `%LOCALAPPDATA%\EbookOrganizer\workspace`，可以切换工作区。
- 原书库（例如 `D:\电子书存放`）保持只读，绝不移动、删除或覆盖。

以用户提供的 EBOOK-ORGANIZER-PROJECT.md v2 为设计依据；本文补上用户新增要求：本地直接上传网盘、保留分类目录、安全同步线上站点、用户选择后检测发布。原文的“不在桌面端自动上传”不再作为产品限制，但仍**复用原有连接器，不重复开发网盘协议**。

## 2. 最终操作流程

1. 打开中文桌面软件，选择 Calibre 导出目录或已分类 EPUB 目录。
2. 后台扫描、完整性检查、计算 SHA-256、分配持久 Book ID。
3. 读取外部 OPF、EPUB 内元数据与封面；显示字段来源、异常、ISBN 校验结果。
4. 优先保留已有分类目录；规则建议与人工修改并存。缺失或歧义不静默猜测。
5. 用户检查资料、分类、授权来源；可批量编辑，也可排除不处理的书。
6. 复制生成分类输出目录、标准封面、导入清单；重复内容不重复导出。
7. 用户主动上传封面至 R2，验证公开图片地址；上传 EPUB 到所选网盘分类目录并生成独立分享。
8. 软件将固定编号、资料、分类、封面 URL、分享链接同步网站，**不将 EPUB 经过网站服务器中转**。
9. 网站预检；管理员确认绑定或创建草稿。明确勾选发布时才检测链接并按网站规则发布。
10. 本地收到回执，分开显示文件上传、分享生成、封面验证、网站同步、发布状态。失败重试只补未完成阶段。

网站上已有的资源整数 ID、resource_code、slug 和有效分享链接保持不变。

## 3. 本轮已有能力与新增边界

已有：FastAPI/Jinja 网站、分类/资源后台、表格导入、网盘链接去重和检测、夸克自动上传分享、上传队列。旧代码按标题猜书，不能直接可靠接受带外部编号的文件。

新增：中文桌面整理软件；可靠身份；资料和封面读取；可解释分类与纠错；只读来源与安全快照；R2；网盘目录对应；同步授权、预检、提交、回执；必要安全修复和恢复工具。

首版主输入为 EPUB + cover.jpg/png/webp + OPF。PDF/MOBI/AZW3等原有网站上传能力不删除，但完整解析、转换及 OCR 不纳入 EPUB 整理引擎；界面必须明确不支持的输入，而非假称识别成功。ISBN优先读取并校验；缺失时标记待补，不联网猜版本、不生成ISBN。联网书目补全可作为独立适配器，未实现时明确禁用。

## 4. 数据和稳定身份

- 每个新内容生成 `BK_` 加完整 UUID；持久化 SQLite 工作区。
- 文件 SHA-256 相同折叠为一个内容记录、多来源；不同内容即使同名也独立。
- 路径和修改时间只用于扫描辅助，不作为身份。改名、搬目录后通过哈希保持编号。
- 原路径内容变了视为新候选，不自动沿用旧版本身份。
- 人工修改锁定，重扫不覆盖；外部附件与原数据冲突显示异常。
- 本地记录 sources、books、issues、jobs、remote_results、site_bindings、exports、settings。
- 网站新增外部身份映射与预检批次，唯一编号、内容哈希、修订号、站点身份联合防错。
- 不以 ISBN 或书名自动合并旧库；首次绑定候选必须在预检中确认。

## 5. 读取与检测

- 元数据优先级：人工值 > 已确认匹配的外部 OPF > 内部 OPF > 文件名推断。
- 同目录多 EPUB 不共用未经确认的附件；作者目录不自动当类别。
- ISBN-10/13 校验；多个候选/不合法值保留问题，不替用户决定版本。
- ZIP 流式 CRC、成员路径安全、container/OPF、manifest/spine/正文引用；不加载外部 DTD、不展开自定义实体、不访问网络。兼容旧书的惰性 DOCTYPE；坏超链接为提示，缺正文/关键附件才拦截。
- 区分 failed（损坏）、blocked（安全/限额/不支持）、warning（缺资料）与 passed。
- 设置单文件、展开尺寸、成员数、单成员、压缩比例和处理时间限额，不能先全部解压再检查。
- 加密正文不处理；已知字体混淆单独区分。EPUBCheck 可选深检，不伪造规范检查结果。
- 不执行 EPUB 脚本、不自动修复、不破解、不联网找书。

## 6. 分类、编辑和界面

Python + PySide6 中文桌面界面，业务服务不依赖 UI。

页面：图书与搜索筛选、资料/封面详情、分类与批量编辑、异常记录、任务与阶段结果、导出、网盘/R2/网站设置。

分类来源：明确目录映射 > 人工结果 > 可解释关键词建议。界面显示证据，不把分数称准确率。主子类通过父子路径匹配；未识别留待处理。重扫不覆盖人工分类。

耗时工作放后台线程；单工作区单写入，支持取消、继续、失败重试。万本列表避免逐项创建昂贵控件；搜索分页或模型视图。关闭时不强杀写文件线程。

## 7. 输出与恢复

每次输出新快照：网盘上传/主类/子类/书名__完整编号.epub；网站封面/编号/版本/cover.webp；数据/books.json、books.csv、upload-manifest.v2.json、manifest.json；异常区报告。

先 staging，完成数量及哈希校验后原子提交。文件名净化且保留完整编号；清单只用相对路径、不泄漏源绝对路径。危险 CSV 公式安全转义，JSON 原值保留。

取消保留已完成状态；遗留 running 标为 interrupted，不声称继续了已完成上传。已上传文件 ID 在创建分享前持久化；分享成功记录后才同步网站，失败不重传文件。

工作区用 SQLite backup 接口备份。恢复只能到新目录或明确空目标，不覆盖运行中的数据库。远端图片/网盘文件永不自动删除。

## 8. 封面及 Cloudflare R2

优先人工封面、明确外部封面、EPUB 显式封面，不拿第一张插图冒充。缺失时可保留网站文字占位；是否进入上传批次由用户确认。

标准图600×900 WebP，等比缩放留边、不裁标题；小图不放大。纠正方向、sRGB、去额外元数据，像素/文件大小限制。原图留私有工作区副本。

key=`books/<Book ID>/<内容及参数版本>/cover.webp`。先 HEAD 对账、PUT、HEAD、公开 HTTPS GET 校验内容哈希，再标 verified。公开地址与 S3 写入 endpoint 分开。仅派生封面上传 R2；不上传 EPUB、原路径或 OPF。

凭据用 Windows Credential Manager/DPAPI；不可用则仅内存。不写普通配置、日志、清单、聊天。最小 bucket 对象权限。应用不创建账户、不改 DNS/公开权限，不擅自发探测对象。

## 9. 网盘上传

夸克沿用官方 CLI，先检查其受支持 Agent 环境；不能伪造身份以绕过限制。桌面独立运行不受支持时明确阻断并保留客户端上传方案，不能把本地开发成功当独立软件授权成功。

用户选择网盘目标父目录；按确认的主/子分类创建/复用目录，记录目录 FID，不随意指向根目录。逐本上传并保存文件 FID，再为该书生成分享，避免给不同图书复用整个分类分享链接。

百度沿用已有上传/分享连接器，令牌必须显式配置，真实上传未验证则在验收中注明。不删除双网盘选项；适配器结构预留其他网盘。

重试幂等键：站点/工作区、Book ID、内容哈希、渠道；内容变更重新确认。上传成功、分享成功、链接可用分别记录。

## 10. 网站安全同步

只传元数据和 URL，不传源路径/EPUB。HTTPS；明确允许 localhost 测试，远程 HTTP 禁止。专用 token 只授予整理同步操作，可撤销；服务器不从请求指定地址加载文件。

新增受保护接口：站点/分类读取、JSON 预检、选择项提交、回执。复用后台认证与 CSRF提供token管理与预检页面；客户端不保存网页登录 cookie。

服务端严格 schema/长度/版本校验，内容数量和请求字节限制。cover_url 映射 cover_image，只允许配置的 HTTPS 图片域名。拒绝未知站点、旧修订、改动后的预检、重复链接和不明确旧资源绑定。

提交按行事务；相同批次重试返回回执，固定 Book ID 重导不新增。默认补空，覆盖非空展示差异并显式选择；已有人工资料、slug、链接不被静默覆盖。

新建默认草稿且必须确认版权类别及来源。发布选项不默认勾选；服务器调用现有链接检测，使用 published+有效可见链接+启用渠道规则。资源归档后旧 /go 链接也应失效。

## 11. 上线收尾（不含服务器购买）

- 默认密码、强 session secret、HTTPS Cookie、管理员禁用即时生效。
- 下架资源旧下载链接检查；导入、API、URL、附件的权限边界。
- 上传任务认领及重启恢复；旧服务多进程适用限制明确记录。
- 封面不依赖易丢失的容器临时目录；SQLite/MySQL迁移分别报告。
- 数据备份、恢复演练、运行日志脱敏、失败可追踪。
- 网站域名/站点ID、sitemap/robots/canonical、手机布局和错误页验收。
- 不把点击量称实际下载量；不保证搜索引擎收录。

## 12. 实施顺序与验收门槛

| 阶段 | 开发内容 | 完成证据 |
|---|---|---|
| A | 文档、目录、契约、合成样例 | 文档落盘、测试与真实数据隔离 |
| B | 只读扫描/检测/元数据/ISBN/编号/分类/封面/快照 | 改名不变号、同名不混、坏书报告、原文件不变 |
| C | 中文桌面界面、人工编辑、后台任务、恢复/备份 | 可以实际启动，扫描预览导出闭环 |
| D | R2、网盘分类上传、同步与网站预检/提交 | mock/隔离测试，错误重试不重传、不重建资源 |
| E | 安全回归、Windows构建、运行与上线说明 | 实测报告，列明云端/干净机器/MySQL未验证项 |

每阶段持续更新实际状态，不把“计划”“界面存在”“mock通过”写成真实云端成功。缺少R2配置、正式站点或网盘授权时仍完成可离线实现部分，不索要聊天明文密钥，不用用户的真实书批量测试。

## 13. 测试矩阵摘要

中文长路径、非法Windows名称、同目录多书、缺封面、多ISBN、恶意XML、ZIP穿越/CRC/炸弹、EPUB2/3/加密；分类手工锁、哈希稳定身份、快照一致性、取消与恢复、磁盘/网络异常。

R2 PUT成功公开失败、断网重试、同key冲突；文件上传成功分享失败、目录复用；token缺失/撤销、跨站点、同包重放、同名不同版本、预检后人工修改、未授权新书、下架旧链接；旧表格导入/上传完整回归。

自动测试禁用现有真实上传与巡检后台，使用合成EPUB、临时工作区、内存网站库和模拟网络。
