# 已知问题与使用限制

公开源码不等于所有流程均已完成真实账号与生产环境验收。使用具体版本前，请检查该版本的测试结果，并用独立小样本验证。

## 网站可以先独立使用

网站提供部署、后台录入、分类、封面、分享链接、前台搜索展示和维护入口，不需要桌面工具才能运行。正式站可以先通过网盘官方客户端上传文件，再在后台录入已有链接。

Linux 部署检查覆盖数据库就绪、HTTPS 与主要页面响应，不会自动验证真实电子书、网盘权限、封面对象或整套业务操作。

## 桌面工具的已知问题

以下问题尚未在当前公开版本中作为完整闭环验收通过：

| 问题 | 影响与建议 |
| --- | --- |
| 新书上传路径调用未定义的 `stage_file` | 夸克 / 百度新文件可能直接失败；不要批量反复重试，先用官方客户端 |
| 全自动流程的百度接入不完整 | 不能因界面可选百度就认为整条流程已可用 |
| 批处理范围、搜索筛选和界面入口存在缺陷 | 操作前确认实际选中项；不建议直接对整个真实书库运行 |
| 全自动流程的资料快照与确认状态可能不同步 | 自动确认后该次处理仍可能跳过，需检查逐本记录，不能只看汇总 |
| 同步汇总可能把收到 HTTP 200 当作成功 | 逐本回执可能仍有错误；必须到网站核对 |
| 已成功状态的复用可能忽略后续资料、封面或发布意图变化 | 修改后不能依赖自动跳过 / 强制选项保证重新同步 |
| 候选绑定和表格回填处理存在异常 | 同名书、数字 ISBN 或空行需特别核对；避免大批覆盖 |
| 全自动任务的持久化与恢复不完整 | 不能把失败后的继续操作等同于可靠断点续传 |

桌面代码属于实验性组件。网站工作流未运行 `tests/test_organizer.py`，网站 CI 通过不能作为桌面端可用的证明。桌面问题的修复应使用独立工作区、模拟服务和小样本重新验证，不应用真实上传来代替自动化测试。

## 网盘和授权边界

- 百度、夸克依赖各自账号授权、官方接口能力和网络条件。
- 夸克连接器对运行环境有要求；普通桌面或服务器环境不保证受支持。不能通过伪造环境身份或绕过连接器检查解决。
- 上传请求失败或超时，不一定表示远端没有生成文件；重试前先核对。
- 网站分享地址检测不检查整本文件内容、格式完整性或实际阅读体验。
- 部分录入路径默认填写“已获授权”；这只是字段默认值，**不是授权验证**。自动分类、元数据和版权记录都需要人工核对来源。

## 网站导入与显示边界

- 传统链接表格导入按规范化书名匹配，不能可靠区分同名不同作者、版本和译本。
- 传统导入会把新资源记为已发布，但链接仍隐藏、待检测；检测通过后可能进入前台。请在导入及检测前审核。
- 元数据导入、传统链接 CSV 和整理工具 JSON 同步是不同入口，不能互换文件。
- 没有完整的批次自动回滚；重要导入和升级之前必须备份。
- 前台只展示已发布且有有效可见入口的资源；全部入口不可用时，图书详情返回 404，而不是持续保留一个维修详情页。
- 网络、登录要求或平台限流可能引起检测误判。自动巡检默认关闭，应在实际环境中验证后启用。

## 部署、备份与规模

- 当前按单服务器、单网站进程设计；未实现多实例任务协调和分布式限流，不应直接横向扩容。
- 未提供某一服务器规格可稳定承载多少本书或多少并发用户的压测保证。
- 正式部署默认关闭云盘上传工作线程；服务器不能读取用户电脑的本地目录。
- 备份含数据库、网站运行文件及私密配置，但不含电脑书库或 R2 对象，且备份本身未加密；需要安全的异地副本。
- Windows SQLite → 生产 MySQL 迁移不是复制数据库文件，需单独设计并验证。
- 恢复失败时网站可能保持停止；不要删卷、清库或重复强制迁移来处理，按维护文档排查。

## 未提供的能力

没有自动联网保证补齐 ISBN、OCR、通用格式转换、访客书评投稿、自动 AI 书评或搜索引擎收录 / 排名保证。网站是资源索引，不附带书籍内容或第三方账号。

问题反馈请提供版本、复现步骤及脱敏错误。不要公开密钥、数据库、完整书库清单或私人分享地址。
