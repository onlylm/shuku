# 已知问题与使用限制

公开源码不等于所有流程均已完成真实账号与生产环境验收。使用具体版本前，请检查该版本的测试结果，并用独立小样本验证。

## 网站可以先独立使用

网站提供部署、后台录入、分类、封面、分享链接、前台搜索展示和维护入口，不需要桌面工具才能运行。正式站可以先通过网盘官方客户端上传文件，再在后台录入已有链接。

Linux 部署检查覆盖数据库就绪、HTTPS 与主要页面响应，不会自动验证真实电子书、网盘权限、封面对象或整套业务操作。

## 桌面工具版本与验证边界

以下为桌面 0.2.0 修复版的处理情况；旧安装包不会自动获得修复。修复使用隔离书库与模拟服务验证，真实云端闭环仍需使用者小样本验收。

| 问题 | 影响与建议 |
| --- | --- |
| 上传准备与百度流程 | 已恢复文件准备函数并接通两种网盘流程；未执行真实账号上传验收 |
| 书库删除、搜索筛选与入口 | 删除先备份后事务移除、刷新列表；空范围不退回全书；保留原文件与云端内容 |
| 分类/版权确认后仍使用旧资料 | 已刷新快照；默认不自动确认版权或分类，来源需人工核对 |
| 网站汇总误计成功 | 已按逐本回执统计同步、失败和实际发布结果 |
| 封面/资料/发布意图变化被旧成功状态掩盖 | 增加版本与配置校验、同步指纹；更新网站非空字段仍需明确选择覆盖 |
| 候选绑定和表格回填异常 | 歧义候选等人工选择；数字 ISBN、空行、重复行和精确匹配已处理；批量回填事务提交 |
| 暂停、取消和继续 | 保存明确范围、参数和逐项结果；在安全检查点停止，复用已确认分享；不保证超时上传可自动恢复 |

桌面代码仍属于实验性组件。网站 CI 通过不能作为桌面端可用的证明；桌面另有 `tests/test_organizer.py` 和 `tests/test_organizer_ui.py`。多电脑授权、全新 Windows 安装和大规模网络故障场景尚未完整验收。夸克环境识别及授权逻辑在本次修复中保持原样。

## 网盘和授权边界

- 百度、夸克依赖各自账号授权、官方接口能力和网络条件。
- 夸克连接器对运行环境有要求；普通桌面或服务器环境不保证受支持。不能通过伪造环境身份或绕过连接器检查解决。
- 上传请求失败或超时，不一定表示远端没有生成文件；重试前先核对。
- 网站分享地址检测不检查整本文件内容、格式完整性或实际阅读体验。
- v2 新建资源默认版权待核验；发布需明确版权类型和来源说明。历史版权记录不会自动重写，自动分类、元数据和版权记录仍需人工核对来源。

## 网站导入与显示边界

- 传统链接表格导入按规范化书名匹配，不能可靠区分同名不同作者、版本和译本。
- v2 传统链接导入的新资源保留为草稿，检测链接不等于发布。请核对分类、版权和来源后再明确发布。
- 元数据导入、传统链接 CSV 和整理工具 JSON 同步是不同入口，不能互换文件。
- 没有完整的批次自动回滚；重要导入和升级之前必须备份。
- v2 已发布图书的资料页不依赖下载入口是否有效；全部入口不可用时保留详情并提示暂无入口。草稿、下架或已删除资源不公开展示。
- 网络、登录要求或平台限流可能引起检测误判。自动巡检默认关闭，应在实际环境中验证后启用。

## 部署、备份与规模

- 当前按单服务器、单网站进程设计；未实现多实例任务协调和分布式限流，不应直接横向扩容。
- 未提供某一服务器规格可稳定承载多少本书或多少并发用户的压测保证。
- 正式部署默认关闭云盘上传工作线程；服务器不能读取用户电脑的本地目录。
- 备份含数据库、网站运行文件及私密配置，但不含电脑书库或 R2 对象，且备份本身未加密；需要安全的异地副本。
- Windows SQLite → 生产 MySQL 迁移不是复制数据库文件，需单独设计并验证。
- 恢复失败时网站可能保持停止；不要删卷、清库或重复强制迁移来处理，按维护文档排查。
- v2 的域名切换和网页升级需要部署专用维护服务。正常设置、备份/恢复逻辑通过自动化测试，不等于所有 Linux 系统与真实域名均已完成验收；正式更新前应完成隔离环境联调。

## 未提供的能力

没有自动联网保证补齐 ISBN、OCR、通用格式转换、访客书评投稿、自动 AI 书评或搜索引擎收录 / 排名保证。网站是资源索引，不附带书籍内容或第三方账号。

问题反馈请提供版本、复现步骤及脱敏错误。不要公开密钥、数据库、完整书库清单或私人分享地址。
