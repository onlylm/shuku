# 表格导入、匹配与审核流程（阶段0）

## 1. 适用规模与目标

第一版面向个人运营，每批几十至几百本。目标不是无人值守，而是让系统完成机械识别、去重和风险提示，管理员只处理真正不确定的记录。

导入不能直接发布。所有记录必须经过预览；自动匹配也允许人工改正，疑似错配必须人工确认。

## 2. 推荐表格格式

最简字段：

```csv
resource_name,share_url
论语,https://pan.example.invalid/s/example
```

标准字段：

```csv
resource_code,resource_name,author,resource_type,provider,share_url,extract_code,copyright_status,source_reference,note
,论语,,book,baidu,https://pan.example.invalid/s/example,1234,public_domain,来源批次A,
```

必填：`resource_name`、`share_url`。其余字段可选。一本资源有多个网盘链接时每个链接占一行；系统将其合并到同一内部资源。

## 3. 处理流水线

```text
上传XLSX/CSV
→ 创建import_batch
→ 保存每一行原始值
→ 校验列名、长度、类型和空值
→ 标准化书名
→ 识别百度/夸克
→ 规范化链接、提取分享ID和提取码
→ 执行重复链接与跨资源冲突检查
→ 匹配已有内部资源
→ 生成置信度和解释
→ 导入预览
→ 人工确认/改绑/新建/忽略
→ 事务提交正式表
→ 分批检测外部链接
→ 检测成功后允许前台显示
```

## 4. 书名标准化

标准化用于候选检索，不覆盖展示标题：

- Unicode NFKC规范化。
- 去除首尾空白，合并连续空格。
- 统一中英文括号、冒号和书名号。
- 将常见格式词如“PDF版、EPUB、高清扫描版”移入格式候选，不盲目删除版本信息。
- 保留译者、出版社、年份、版本等可能用于区分同名书的信息。
- 生成 `normalized_title` 和匹配用tokens，并保存标准化前后的差异。

## 5. 链接识别与去重

每个平台解析器返回：

```text
provider_code
normalized_url
provider_share_id
extract_code_candidate
parse_warnings[]
```

检查顺序：

1. URL语法和HTTPS校验。
2. 域名白名单与平台识别。
3. 去除跟踪参数、无意义尾斜杠，统一允许的URL形式。
4. 提取分享ID。
5. 计算 `SHA-256(normalized_url)`。
6. 查询导入批次内部是否重复。
7. 查询正式数据库是否已有相同URL哈希。
8. 查询平台分享ID是否已经存在。
9. 查询已有链接所属资源是否与本行候选资源冲突。

结果分类：

- `duplicate_same_resource`：已属于同一资源，默认跳过。
- `conflict_other_resource`：已属于其他资源，阻止自动提交。
- `duplicate_in_batch`：同批重复，只保留首行并提示。
- `new_link`：可继续匹配。
- `unsupported_provider`：进入人工处理，不写正式链接。

## 6. 资源匹配

按以下优先级生成候选：

1. `resource_code` 完全匹配。
2. 渠道分享ID或渠道编码已经绑定。
3. ISBN完全匹配。
4. 标准书名+作者完全匹配。
5. 标准书名+出版社+年份匹配。
6. RapidFuzz模糊匹配并结合作者等字段加权。
7. 无可靠候选时建议新建草稿。

建议置信区间：

- 95—100：高置信自动建议，仍显示在预览中。
- 75—94：需要人工确认。
- 0—74：不得自动合并，建议新建或手动选择。

阈值必须通过真实样本测试调整，不能把评分本身视为事实。

## 7. 错链识别

错链使用多信号判断：

- 同一分享ID已经绑定另一内部资源：强冲突。
- 分享页公开文件名与导入书名明显不相似：阻断警告。
- 文件夹内存在多本书：建议改为合集或人工确认。
- 分享页无法访问、要求登录或验证码：标记“无法验证”，不推断失效。
- 表格平台字段与实际域名不同：使用实际域名并提示。

系统不绕过登录、验证码或平台限制。无法读取分享页文件名时，以表格行关系为来源，但必须在预览中显示“内容未验证”。

## 8. AI辅助边界

AI可以：

- 推荐最可能的已有资源。
- 解释标题差异和疑似版本信息。
- 标记“可能是合集”“可能放错链接”。
- 对人工选项排序。

AI不可以：

- 自动改写ISBN、作者、出版社、年份和版权状态。
- 在低置信度时强行合并。
- 跳过唯一约束。
- 未经确认直接发布或公开新链接。

## 9. 预览页面

每行展示：行号、资源名、平台、链接摘要、匹配资源、置信度、链接状态、问题和处理选择。

筛选项：全部、可导入、新建资源、重复链接、疑似错链、字段错误、待确认。

批量操作：确认高置信匹配、忽略重复、将选中记录设为新建草稿。跨资源链接冲突不得批量忽略。

提交按钮旁显示：预计新建、更新、跳过、警告、阻断数量；存在阻断错误时禁止提交。

## 10. 提交与回退

- 提交使用幂等键，重复点击不会重复写入。
- 每50—100行一个数据库事务；单行失败不污染其他已确认分块。
- 正式数据保存 `source_batch_id`，支持按批次查看和撤销本批新增关系。
- 撤销不删除已有资源，只回退本批新增链接、渠道关系和草稿，并写操作日志。
- 提交完成后生成CSV错误报告。

## 11. 外部链接检测

导入预览不等待几百个外部请求。确认提交后创建检测任务，每批10—20个，限制并发和频率。

新链接初始为 `unchecked`，前台不可见。检测明确正常后变为 `active`；不确定失败为 `suspected`；明确失效为 `invalid`；验证码和频率限制保留原状态并延迟重试。

## 12. 验收样例

测试数据至少包含：完全重复URL、不同写法的相同URL、相同分享ID、链接已绑定其他图书、同名不同作者、同一本书多格式、多渠道同书、无法识别平台、无效URL和分享页不可验证。
