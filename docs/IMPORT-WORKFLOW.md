# 表格导入与审核

本页说明网站后台导入，不是桌面工具的 CSV 回填或 JSON 同步操作。首次录入建议先用 10–20 本确认结果，再扩大批次。

## 选择正确入口

| 资料类型 | 入口 |
| --- | --- |
| 书名与已有网盘分享链接 | 后台“表格导入”，`/admin/import` |
| 书目资料表 | 元数据导入，`/admin/import/meta`，按页面模板与预检操作 |
| 整理工具的 v2 JSON 包 | 专用同步接口，不能当作普通 CSV 上传 |

同步流程见 [接口说明](API-DESIGN.md)。

## 链接表格操作

1. 从后台下载模板，或使用仓库中的 [CSV 模板](../app/static/samples/import-template.csv)。
2. 必填“书名”和“网盘链接”；可补作者、ISBN、出版社、出版年份、简介、语言、格式、分类、提取码、版权状态和来源说明。
3. 分类应先在后台建立，填写已有分类名称。同名分类或同名不同版本图书请分开核对。
4. 上传 CSV 或 XLSX，进入预检页。文件大小和行数以服务器 `IMPORT_MAX_BYTES`、`IMPORT_MAX_ROWS` 配置为准，建议分批处理。
5. 检查每行匹配对象和提示，只勾选确认正确的行。重复、冲突和错误行不能直接提交。
6. 提交后到“资源管理”核对资料，再执行链接检测，在前台抽查实际跳转和文件。

CSV 支持 UTF-8（含 BOM）和 GB18030；XLSX 读取当前活动工作表。ISBN 建议用文本单元格，防止表格软件改写数字。

## 预检状态

| 状态 | 含义与处理 |
| --- | --- |
| 可导入 | 可新建资源或为匹配资源补链接；仍需检查匹配是否正确 |
| 警告 | 书名与已有记录相似，需要人工判断是否是同书或不同版本 |
| 同批重复 | 同一批次里已出现相同链接 |
| 已有重复 | 该资源已有相同链接 |
| 冲突 | 链接已属于其他资源，停止该行并核对来源 |
| 错误 | 缺少必填项、链接格式错误或不支持的平台 |

当前传统导入主要按规范化书名匹配，**不是基于 ISBN、作者和版次的可靠多字段鉴定**。相同书名可能匹配到不同版本；不要仅凭“可导入”确认内容一致。

对新资源，分类只关联已存在的同名分类，不会在此入口自动建立所有分类。导入现有资源主要是补充链接，不等同于覆盖整本书资料。

## 提交后的状态

**传统链接表格导入会把新资源记录设为“已发布”，但新链接仍为“待检测、隐藏”。** 检测通过后可能进入前台，不会再额外等待一次发布确认。因此，应在提交和检测前完成资料、版权和来源核对。

已有资源保留其原发布状态。整理工具的 JSON 同步则默认新建草稿，两者行为不同。

再次提交同一传统导入批次会被拒绝；没有“一键撤销整个批次”的接口。导入前备份，错误记录通过后台人工修正。不要把早期设计中的回滚、AI 自动匹配或文件内容校验当作现成功能。

## 检测与后续维护

后台记录“有效”说明链接检测通过，不保证文件内容、版本和实际下载一定正确。网络异常、登录要求、平台限流都可能影响检测结果。

遇到不显示、错误匹配或失效入口，按 [后台使用说明](使用说明.md) 排查；更完整的功能边界见 [已知问题与使用限制](已知问题与使用限制.md)。
