# 开发指南

本页面向维护者。只想安装网站，请使用 [部署说明](部署说明.md)，不要将下面的演示配置用于公网。

## 1. Windows 本地环境

需要 Python 3.12 和 Git。在选择好的开发目录打开 PowerShell，依次运行：

```powershell
git clone https://github.com/onlylm/shuku.git ebook-site
cd ebook-site
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

新克隆的代码不包含虚拟环境、数据库、电子书、封面或凭据。

首次建立本地演示数据库并运行：

```powershell
$env:CLOUD_UPLOAD_WORKER_ENABLED = "false"
$env:LINK_CHECK_AUTOMATIC_ENABLED = "false"
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m scripts.seed_demo
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

打开 `http://127.0.0.1:8000/`，后台为 `/admin/login`。默认演示账号为 `admin / ChangeMe123!`，可由配置覆盖，**仅限隔离的本地测试**。

演示初始化会写入测试数据，只用于新建的本地开发库，不要对正式数据库运行。根目录 `.env.example` 说明开发配置；生产由部署脚本生成独立的 `deploy/.env`。

Linux / macOS 开发使用相同模块命令，将 Python 路径替换为 `.venv/bin/python`，设置环境变量时使用相应 Shell 语法。

## 2. 网站测试

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pytest -q --ignore=tests/test_organizer.py
```

测试配置关闭真实上传和巡检线程，并用隔离数据库验证网站行为。不要把真实账号凭据作为测试依赖。

[GitHub Actions](https://github.com/onlylm/shuku/actions) 还包含 Linux Docker 镜像构建、MySQL 迁移、重复初始化、配置排除和备份校验。查看对应提交结果，不把某一次通过当作全部版本都通过。

桌面测试独立执行，并可能遇到 [已知问题](已知问题与使用限制.md)。不要为了“全绿”删除失败用例或将桌面端描述为已通过生产验收。

## 3. 桌面工具开发

Windows 下安装桌面依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-organizer-win.lock
.\.venv\Scripts\python.exe -m ebook_organizer --workspace .\runtime\organizer-test
```

锁定清单针对 Windows 环境；其他平台不在该桌面包验证范围内。源码启动工作区与打包版默认工作区不同，见 [工具说明](本地整理软件使用说明.md)。

需要构建时，先验证离线与模拟测试，再运行：

```powershell
.\scripts\build_organizer.ps1
```

输出在 `dist/EbookOrganizer/`，该目录不会提交 Git。构建成功只说明生成了程序，不代表全新 Windows 安装、真实云端授权或批量上传均已验证。

## 4. 修改与提交

业务入口与模型见 [系统架构](ARCHITECTURE.md)、[数据模型](DATABASE-SCHEMA.md)、[接口说明](API-DESIGN.md)。

- 模型变化应增加 Alembic 迁移，不改已经应用的历史迁移来绕过升级。
- 先检查已有工作区修改，只暂存本次相关文件。
- 配置、凭据、数据库、书籍、运行数据和个人交接资料留在本地，不加入公开仓库。
- 本地忽略规则不能清除已提交的 Git 历史；已经泄露的密钥应撤销或轮换。

暂存准备发布的文件后执行：

```powershell
.\.venv\Scripts\python.exe scripts/check_public_release.py
git diff --cached --check
git diff --cached --stat
```

发布检查读取 **Git 索引（暂存区）**，不是全部本地文件；未暂存的新内容不会被检查。脚本只覆盖列出的禁传路径和令牌模式，不能替代人工审查。

更新服务器请使用 `sudo bash deploy.sh update`，不要把开发库、整台电脑目录或本地整理工具输出直接覆盖到生产目录。
