# 阶段一验收说明

## 完成目标

阶段一把阶段零的静态原型变成了可运行的资源索引系统，打通“人工整理表格 → 系统预检 → 人工确认 → 入库 → 链接检测 → 前台显示 → 失效隐藏 → 后台替换 → 检测通过恢复”的完整闭环。

## 验收场景

1. 未登录访问后台页面会跳转登录页；错误密码受到进程内限流保护。
2. 上传包含重复链接的 CSV/XLSX 时，同批次第二条被标记为重复。
3. 同一网盘分享链接即使提取码不同，也会被识别为同一分享。
4. 已属于 A 资源的链接再次随 B 资源导入时，系统标记为冲突并禁止提交。
5. 新导入链接状态为 pending，前台不可见。
6. 检测有效后链接变为 active + visible，资源详情页显示渠道按钮。
7. 页面明确返回失效时立即隐藏；临时网络错误达到配置的连续失败阈值后才隐藏，后台保留记录和替换入口。
8. 替换链接后立即检测；有效自动恢复显示，无效继续隐藏。
9. `/go/{link_id}` 只允许有效可见链接跳转，并记录点击；其他状态返回 410。
10. 零结果搜索写入后台统计；sitemap 只收录有有效入口的已发布资源。
11. 全部资源、分类、搜索、后台资源和链接列表支持分页，可承载数千条记录浏览。
12. 自动巡检启用后，系统按配置间隔分批检测到期链接；有效链接恢复显示，失效链接自动隐藏。

## 尚未进入本阶段

- 百度/夸克账号授权、自动上传、自动转存和自动生成分享链接。
- 多人角色权限、分布式队列和大批量并行导入。
- 服务器正式域名、HTTPS、备份和监控落地。

这些属于后续服务器部署和网盘自动化阶段，不影响阶段一的人工表格导入与前后台闭环验收。
