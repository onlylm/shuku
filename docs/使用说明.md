# 网站后台使用说明

开始前请完成 [部署](部署说明.md)，并用初始管理员账号登录自己网站的 `/admin/login`。首次启动为空书库，这是正常现象。

## 1. 先建立分类

打开“分类管理”，新建或编辑分类，设置父分类、排序与是否显示。分类不是固定写死的；录入图书时可选择已有分类。

分类有资源关联或子分类时，先处理这些关联，再按后台提示删除。已有分享链接所属网盘还需在“网盘渠道”中启用。

## 2. 新建一本图书

进入“资源管理 → 新建资源”，填写书名，按资料来源补作者、ISBN、出版社、格式、分类和简介。

- 不知道的书目字段可留空，不要填猜测的 ISBN 或版次。
- 分类、版权状态和来源说明由操作者核对。表单默认值不代表系统已核实授权。
- 封面可填写可访问的图片 URL，或选择本地图片上传；同时提供时以文件上传为准。
- 图片上传支持 JPG、PNG、WebP、GIF，当前上限 5MB。未提供封面时使用文字占位。
- 简介由后台编辑，当前没有访客投稿式书评系统或自动 AI 书评功能。

确认发布状态为草稿后保存，可继续整理，前台不会显示。不要在资料尚未核对时点击“保存并发布”。

## 3. 添加分享入口

在资源编辑页填写百度或夸克分享链接，必要时填写提取码。系统根据支持的链接域名识别网盘，前台显示对应网盘名称。

新链接先进入待检测状态，默认不公开。使用“立即检测”，查看结果；无法检测时先手动打开网盘链接排查，不要反复强制重试。

“链接已属于其他资源”通常表示粘错了链接或重复录入，应确认真实归属。一本书多个网盘链接可以共存，不要把不同书共用的整类分享当作独立入口。

## 4. 发布并检查前台

资料和来源确认后，点击“保存并发布”，或把发布状态改为“已发布”并保存。

前台显示还需要至少一个有效、允许显示的入口，且所属网盘渠道启用。发布后请打开前台，检查书名、分类、封面、简介、提取码与实际跳转。

**后台有记录、前台没有时，依次检查：**

1. 资源是否仍是草稿或已归档。
2. 是否已有分享链接，检测是否通过。
3. 链接是否被隐藏，平台或渠道是否停用。
4. 图书是否关联了正在查看的分类，分类是否显示。

资源已发布但没有有效入口时，当前详情页也可能返回 404。修复链接后重新检查，不需要重复建立同一本书。

## 5. 分批录入

已有资料表可以从“表格导入”上传 CSV / XLSX，先预检再确认，具体见 [表格导入与审核](IMPORT-WORKFLOW.md)。

注意：传统链接表格导入的新资源会标为已发布，新链接仍待检测、隐藏。检测有效后可能直接展示，因此审核应在提交与检测之前完成。这个流程与手动草稿、桌面同步默认草稿不同。

刚开始先录入 10–20 本，通过前台验收后再扩大规模。

## 6. 下架、删除和链接维护

- 暂时下架：将发布状态改为草稿或已归档，再保存；这比永久删除更容易恢复。
- 链接失效：在编辑页替换地址并重新检测，不必删除图书资料。
- 永久删除：资源编辑页提供删除入口；会删除相关网站记录，操作前确认对象并备份。
- 网站删除资源不等于自动删除网盘文件或 R2 对象；远端内容需要单独管理。

链接检测是辅助工具，平台登录要求、限流或网络波动可能影响判断，不等于验证了文件内容和下载可用性。

## 7. 其他管理与日常维护

“友情链接”可管理页脚外链；“访问数据”可查看跳转、访问和搜索记录。只根据真实数据判断运营情况，不把 SEO 标签或收录文件当作排名保证。

正式站的云盘上传工作线程默认关闭。后台路径指运行网站的机器，不是浏览器所在电脑。无需等桌面工具完善，可以先通过官方网盘客户端上传并录入已有链接。

定期备份，修改配置或更新前先阅读 [Linux 配置与维护](Linux一键部署指南.md)。上线前还应检查 [已知问题与使用限制](已知问题与使用限制.md)。
