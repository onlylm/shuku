# 本地整理工具使用说明（实验性）

此工具是网站之外的 Windows 桌面组件，源码位于 `ebook_organizer/`。桌面 0.2.0 修复版修正了书库移除、上传准备、筛选、表格回填和逐本同步结果处理。**自动化验证使用临时书库和模拟服务，不等于真实账号验收；首次请只选 1～2 本测试。** 先阅读 [已知问题与使用限制](已知问题与使用限制.md)。

网站无需安装此工具即可运行；正式运营可先用网盘官方客户端上传，再通过网站后台录入资料和分享链接。

## 1. 启动和工作区

源码环境安装、启动命令见 [开发指南](开发指南.md)。仓库不附带便携版安装包；自行构建后需要保留完整输出目录，不能只复制 EXE。

- 源码启动默认工作区：项目中的 `runtime/organizer/`。
- 打包版默认工作区：当前 Windows 用户的 `%LOCALAPPDATA%\EbookOrganizer\workspace`。
- 可用 `--workspace` 指定独立工作区；原书库、工作区、导出目录不要互相嵌套。
- 不要同时启动多个程序操作同一个工作区。

工作区包含稳定图书编号、人工修改、处理结果与封面等数据，不是可随意清除的缓存。

## 2. 先验证离线扫描

准备一个只有少量测试 EPUB 的独立文件夹。在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m ebook_organizer --workspace .\runtime\organizer-test --scan "E:\ebook-test"
```

将 `E:\ebook-test` 替换为自己的测试目录。此命令仅执行离线扫描，不启动界面、不发起云端上传。

扫描尝试从 OPF / EPUB 读取书名、作者、出版信息、ISBN、简介和封面；缺失或有歧义的内容需人工核对。它不会联网保证补齐 ISBN，也不负责格式转换、OCR 或 DRM 破解。

分类目录和关键词只提供规则匹配，不能把作者目录、杂乱标签或自动建议直接当作准确分类。原文件应另行备份；先用副本验证操作。

书库页顶部提供扫描、继续扫描、导出和“删除选中图书”。搜索支持书名、作者、ISBN 和编号，并与分类及状态筛选叠加。上传按钮优先使用明确选中的图书；没有选中时使用当前筛选结果，执行前会显示范围供确认。空筛选不执行全书操作。

### 删除已导入图书

1. 在书库表格点选图书；按住 Ctrl / Shift 可多选。
2. 点击顶部“删除选中图书”，或在表格内按 Delete、右键选择“从工作区移除”。
3. 核对数量并确认。运行中先取消或等待任务结束。
4. 软件先备份，再一次性移除选中的本地记录并刷新列表。取消或出错时不会只删半批。

**删除不删除电脑原始电子书、网盘文件、网站资源或本地封面缓存。** 删除前的数据库快照保存在工作区 `backups/before-remove-*.sqlite3`，结果窗口显示具体路径；这是资料快照，不是 ZIP 工作区备份，请勿当作 ZIP 导入，也不要直接覆盖正在使用的数据库。需要恢复时，先退出软件并备份当前完整工作区。

重新扫描原始文件会再次导入并可能产生新编号；只想让图书暂时不参与上传、保留编号和结果，应使用“排除”。已发布网站资源应在网站后台另外管理。

### 表格回填

支持 UTF-8 / GB18030 CSV 和 XLSX，每次不超过 20000 行、20 MiB。优先用图书编号匹配；ISBN 和书名仅做精确匹配，同名多版本、重复行会提示并跳过，不模糊合并。默认只补空字段；明确选择“覆盖表格提供的非空字段”后才覆盖旧资料，空字段不清空旧值。两种方式均需预检确认；预检后资料发生变化时需重新预检。

## 3. 封面与 R2 配置

仅在准备小样本联调时填写云端配置；只做离线整理不需要 R2。

| 设置 | 填写内容 |
| --- | --- |
| R2 账户编号 | Cloudflare 账户的 32 位编号，不是 API Token |
| R2 存储桶 | 存储桶的实际名称 |
| 公开图片域名 | 绑定存储桶的 HTTPS 图片域名，不是 S3 API 上传地址 |
| Access Key ID / Secret | 相应存储桶的 S3 对象读写凭据 |

R2 流程上传处理后的封面，不上传 EPUB。对象路径按图书编号与封面版本组织，通常为 `books/图书编号/封面版本/cover.webp`。

存储桶、公开域名与凭据须自行准备，工具不自动开户或修改 DNS。上传后验证公开地址；封面版本、R2 账户、存储桶或公开域名发生变化时会重新处理。旧版本缺少配置校验信息的结果也会重新验证一次。

凭据通过 Windows 系统凭据库保存，不可用时仅在当前进程保留。不要把凭据填进表格或提交到 Git；工作区备份不包含系统凭据。

## 4. 网盘文件和分享链接

夸克和百度需要各自的平台授权；授权成功不代表已具备所有上传、分享权限。

- 夸克使用官方连接器，需要其支持的运行环境。目标目录填写真实文件夹编号，根目录才填 `0`；不能把分享编号当成文件夹编号。
- 百度使用已取得的授权令牌和目标目录；令牌过期需重新处理授权。
- 新文件先复制到工作区临时上传目录并核对哈希，不修改原 EPUB。夸克和百度都已接入该流程，真实账号权限、限流与稳定性仍需各自验证。
- 遇到连接器拒绝当前环境，不要通过伪造标记或修改连接器绕过检查，改用官方客户端。

可先用官方客户端将测试 EPUB 按分类上传，为每本书建立独立分享链接，再在网站后台录入。不要把一个整类目录的链接分配给多本不同图书。

请求超时或任务失败不一定表示远端没有文件；重试前先检查网盘，避免重复上传。

## 5. 网站同步配置

同步属于独立的实验性工作流。桌面按逐本回执统计结果，HTTP 200 不直接计为成功；仍需到网站核对最终展示。

1. 登录网站 `/admin/organizer` 创建专用同步授权，妥善保存只显示一次的明文。
2. 在工具中填写网站地址、后台显示的站点编号和同步授权。使用实际网站地址，不填图片域名。
3. 正式网站必须 HTTPS。本地开发可使用 `http://127.0.0.1:8000`，前提是网站确实运行在该端口。
4. 使用远程封面时，服务器 `deploy/.env` 的 `ORGANIZER_COVER_HOSTS` 应包含图片主机名；本地开发对应根目录 `.env`。修改后按部署文档重新启动。
5. 先预检少量图书，核对候选资源、分类、封面、版权来源与链接。不能将不明确的候选直接绑定到第一本书。
6. 提交后检查逐本回执，再登录网站后台确认资源状态，最后从前台验证。

“文件上传成功”“分享已生成”“资料同步成功”“链接有效”“已发布”不是同一个状态。修改元数据、封面、站点配置或发布意图后会重新检查同步；有同名候选时停在待人工绑定，不自动选择第一本。

默认仅补网站空字段；要更新已有标题、简介、封面等非空资料，明确勾选“覆盖”。分类仍按网站合并规则处理，不代表删除原分类。希望前台展示时勾选发布，网站链接校验通过才发布，归档资源不会自动恢复。预检后又修改或删除本地图书，应重新预检。

任务中心提供暂停、取消和“继续上次流水线”，在当前网络操作结束后的检查点生效。继续时按上次的明确书目和设置处理，复用已确认的文件/分享结果；“重新校验封面并同步网站”也不会重复上传已有分享的书。上传结果不确定时仍需人工检查网盘，不能当作远端文件不存在。

协议、每批上限和可接受动作见 [接口说明](API-DESIGN.md)。普通网站 CSV 模板与桌面导出清单不同，不要混用。

## 6. 备份与反馈

同时备份原始 EPUB 和工作区。只保存导出的 CSV 不能恢复人工锁定、稳定编号和同步记录。更换电脑后需重新设置凭据，并核对本地源文件路径。

发生问题时，提供软件/代码版本、操作步骤和去除个人数据后的错误信息。不要公开工作区数据库、书库清单、分享链接、账号凭据或完整日志。网站的生产备份不包含电脑书库及 R2 对象，见 [Linux 配置与维护](Linux一键部署指南.md)。
