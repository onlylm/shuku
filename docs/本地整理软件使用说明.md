# 电子书整理工作台：使用说明

版本 0.1.0，2026-08-31。面向个人管理 EPUB 书库。无需把本地电子书先传到网站服务器。

## 1. 从哪里打开

便携版：`D:\网盘拉新\dist\EbookOrganizer\EbookOrganizer.exe`。

双击打开。移动到别的位置或另一台电脑时，必须复制整个 `EbookOrganizer` 文件夹，不能只拿 exe。基础整理包含 Python 和 Qt 运行环境；不需要额外安装 Python。未做代码签名，也未在全新 Windows 机器验收，不建议直接对外分发。

源码：`D:\网盘拉新\ebook_organizer`。开发启动脚本：`D:\网盘拉新\scripts\start_organizer.ps1`。

默认工作区：

- 双击便携版：`C:\Users\Administrator\AppData\Local\EbookOrganizer\workspace`，换用户后对应其本地应用数据目录。
- 源码启动：`D:\网盘拉新\runtime\organizer`。
- 两者默认不是同一工作区。可在“任务与异常 → 切换工作区”选择同一个目录；同一工作区不能同时打开两份程序。
- 原书库、工作区、导出目录应为彼此独立的目录，不要互相嵌套。

## 2. 先做一小批离线整理

1. “书库整理 → 选择目录并扫描”，选择 Calibre 导出的文件夹，或已按类别整理的 EPUB 文件夹。
2. 软件读取书名、作者、出版社、出版年份、语言、ISBN、简介和明确声明的封面。ISBN 校验不通过或存在多个候选时留待核对，不联网猜版本。
3. 点击图书查看右侧资料和提示。补充或纠正分类；“分类建议”只填入建议，点击“保存此书”后才确认。
4. 人工编辑会锁定字段；重新扫描不会覆盖。可以撤销上次资料修改。手选封面保存到工作区，不修改原图片。
5. 按住 Ctrl / Shift 多选。“将分类和授权应用到选中图书”只批量改分类与版权/来源，不会把一本书的书名或作者复制给其他书。
6. 选中要处理的书，点击“导出选中图书”，选择一个独立输出目录。

可以直接使用 `D:\网盘拉新\samples\organizer` 下的合成样例熟悉目录。样例不是实际出版物，ISBN仅作格式测试，不表示这些合成书真实取得该书号。

原 EPUB 只读，扫描不会自动上传、移动、删除或改写。相同内容只形成一个图书编号；同名不同内容保留为不同版本。工作区数据库决定稳定编号，请定期备份。

## 3. 分类怎么处理

- 已知分类目录优先，例如 `文学小说\中国文学\某书.epub`。
- 扫描根目录本身就是已知类别时也能识别，例如直接选择“文学小说”目录。
- Calibre 的作者目录、杂乱标签不直接当成网站类别；只有明确规则才给建议。
- 默认包含文学、历史、计算机、科普等规则；可在“连接与分类设置”修改关键词。
- 本地分类名与网站不同，可配置对应关系。例如 `{"历史文化/中国历史": ["历史人文", "中国历史"]}`。这只改变网站目标分类，不改变本地或网盘目录名。
- 网站尚无对应类别时，提交会按明确的父子名称建立。旧库有同名歧义时停止该项，不随意选第一条。

自动分类不是内容审核或准确率保证。上传前必须人工确认分类和版权来源。

## 4. 导出后会得到什么

```text
export_时间_编号/
  网盘上传/主分类/子分类/书名__BK_完整编号.epub
  网站封面/BK_编号/封面版本/cover.webp
  网站封面/BK_编号/封面版本/thumb.webp
  数据/books.json
  数据/books.csv
  数据/books.ready.json
  数据/upload-manifest.v2.json
  数据/manifest.json
  数据/jingye-import.v2.json       # 配置站点后生成；超过500本分片
  异常区/issues.json
  README.txt
```

网盘上传目录只含通过基础检查的 EPUB；异常或已排除记录不混进去。未确认分类的离线副本进入“待人工分类”。导出不等于已授权、已上传或已发布。

清单不包含原书库绝对路径或凭据。`books.csv` 用于查看，不是旧网站“表格导入”的模板。常规使用直接在软件点“网站同步预检”，不要把新清单当旧 CSV 上传。

每次导出新快照，不覆盖旧快照。复制按内容哈希核验；失败/取消时 `.staging_...` 是未完成产物，不能当作正式上传包。它不会自动删除，确认不需要后可在独立输出目录人工清理。

## 5. 封面上传到 Cloudflare

只上传处理后的 `cover.webp`，不会把 EPUB、OPF 或原图上传到 R2。缩略图目前留本地，网站列表和详情共用标准图。

在“连接与分类设置”填写：

| 设置 | 应填写的内容 |
|---|---|
| R2 账户编号 | Cloudflare 账户的32位编号 |
| R2 存储桶 | 你准备用于封面的 bucket 名称 |
| 公开图片域名 | 已绑定此存储桶的 HTTPS 自定义域名，不是 S3 API 地址 |
| R2 Access Key ID / Secret | 仅限相应存储桶对象读写的 S3 凭据 |

软件不自动创建账户、存储桶或修改 DNS。公开域名必须能读到对象；不能仅凭“上传成功”认定图片可用。写入后会读取公开地址比对内容，再把 URL 交给网站。

对象位置：`books/图书编号/封面版本/cover.webp`。改封面产生新版本地址，不覆盖旧缓存。同地址内容冲突会停止。

凭据只存 Windows 系统凭据库；系统凭据库不可用时仅本次运行有效。留空保存不会清除旧凭据。不要把密钥放到聊天、表格或 Git。工作区备份不包含系统密钥。

没有封面可先保留网站文字占位，不要勾选该书的封面上传。缺少封面的批次不能直接使用要求封面成功的组合上传按钮，可分别上传图书、再同步。

## 6. 夸克与百度上传

先在右侧确认版权状态和来源说明，并保存。这里只记录你的确认，不会代替你核实授权是否有效。

### 夸克

1. 使用“安装官方夸克连接器”，或指定现有官方连接器文件路径。
2. 连接器需要可用 Node.js；便携包不捆绑 Node.js 或网盘账号。
3. 填写目标父文件夹编号，明确使用网盘根目录才填 `0`。不要把分享链接编号当作父文件夹编号。
4. 点击“检查夸克授权”；确有需要时点击“主动授权夸克”。
5. 选书并选择“夸克网盘”，点击“上传选中图书到网盘”。软件按主/子分类建目录，为每本书生成独立分享。

**重要限制：官方连接器要求受支持的 Agent 环境。当前开发环境可以识别，模拟普通桌面启动不被识别。普通双击 exe 的夸克全自动上传目前不保证可用，软件会明确阻止，不会伪造身份。**

可用替代路径：将“网盘上传”目录通过官方客户端上传；为每本书创建独立分享，再在软件中“手工回填分享链接”。不要把同一个整类文件夹分享回填给不同的书。网站还会进行全局重复链接检查。

本轮没有用真实图书重新上传验证，原网站历史成功任务不是桌面版成功的证明。

### 百度

填入你已取得的百度网盘授权令牌和目标目录。选“百度网盘”后上传。软件先建立分类目录、上传，再生成分享；令牌过期需要更新。没有加入网页登录账号密码或私有 Cookie 方案。

此通路已接入已有官方上传/分享实现，但未做真实账号联调。权限、分享能力、路径限制是否满足，仍需用你确认可测试的小样本实际验收。

两种网盘顺序选择执行即可；软件不同时并发上传大量文件。其他网盘尚无实际适配器。

### 重试规则

文件编号已保存、分享失败：重试只补分享。上传请求发出却没拿到结果：不盲目重传，先在网盘核对，必要时手工回填。已成功分享会复用；若切换到另一个网盘账户，应使用独立工作区，避免复用原账户记录。

## 7. 把资料同步到网站

网站后台新增“本地软件对接”：`/admin/organizer`。

1. 登录网站后台，在该页创建专用同步授权。授权明文只显示一次，复制到本地软件的“网站同步授权”。不要使用管理员密码代替。
2. 本轮新代码测试地址为 `http://127.0.0.1:8001`，请覆盖软件默认的8000并保存；8000旧进程未强行停止。正式网站必须 HTTPS。站点编号需要两端一致，本地默认 `jingye-local`。
3. 如果使用 R2 图片，网站 `.env` 需配置 `ORGANIZER_COVER_HOSTS=你的图片域名`。只填域名，不含协议和路径；多个用英文逗号分隔。修改后重启网站。
4. 点击“检查网站并读取分类”，再回书库选中1～500本，点“网站同步预检”。第一次建议10～20本。
5. 查看预检：有稳定编号的更新原资源；旧库同名/同ISBN只列候选，由你确认绑定，或明确选择新建不同版本。
6. 默认仅补空字段，新书为草稿。确实要覆盖旧资料才勾选覆盖。
7. 确实要发布，勾选“链接检测通过后自动发布”，再确认提交。
8. 阅读逐本回执。软件按书提交并保存回执；断网后可“恢复上次预检 / 重试提交”，已成功项不重复建立。

网站只收到资料、封面地址和分享地址，不会收到本地硬盘路径，不会从你的浏览器读取电脑文件。

“同步成功”“文件上传成功”“分享已生成”“链接当前有效”“已发布”是不同状态。没有有效入口仍不会在前台出现；已归档的资源不会被自动恢复。原网站地址、资源编号、有效旧分享不随本地导入重新生成。

旧批次提交成功后改变发布选项，不会在重放中重新执行；应重新预检产生新批次，或在网站后台发布。

## 8. 暂停、继续、备份与恢复

- 任务中心可暂停/取消；已经发出的网络请求要等待当前请求结束，取消不删除远端对象。
- 扫描中断后点“继续上次扫描”；按哈希复用身份，但会重新核验文件，不是跳过所有读盘。
- 云任务失败可“重试上次云端任务”；不自动无限重试。
- 关窗口时有任务运行会先请求停止，等待完成再关，避免强杀写文件。
- “备份工作区资料”生成含 SQLite 一致性备份、封面与原 OPF 的 ZIP，不包括源 EPUB、上传暂存文件和系统凭据。
- “恢复到新工作区”只恢复到新目录，不覆盖现有数据；随后“切换工作区”打开恢复结果。
- 换电脑后需另行复制原书库、重新扫描关联路径，并重新设置云端/网站凭据。

不要只备份导出 CSV：它不足以恢复人工锁定、全部来源、远端文件编号及同步回执。
