# 静页书房桌面整理软件（ebook_organizer）技术文档

> 版本：2026-08-31 整理
> 适用范围：PySide6 桌面端（扫描 / 整理 / 封面上 R2 / 传网盘 / 同步网站）+ 全自动流水线
> 配套网站端见 `app/`（FastAPI），本文重点在桌面端。

---

## 1. 项目定位与两端架构

「静页书房」是一个产品、两端代码：

| 端 | 技术栈 | 位置 | 职责 |
|---|---|---|---|
| 网站端 | FastAPI + Jinja2 + SQLite/Alembic | `D:\网盘拉新\app` | 公版/开放许可图书索引站，接收桌面端元数据做发布 |
| 桌面端 | PySide6 / Qt | `D:\网盘拉新\ebook_organizer` | EPUB 只读扫描、哈希去重、稳定 Book ID、分类、封面、导出、传网盘、同步网站 |

**两端对接方式**：
- 桌面端通过网站发放的**专用可撤销 token** 调 `/api/v1/organizer`（`info` / `preview` / `commit`）。
- 只传**元数据 + 封面 URL + 分享链接**，**不传源文件/EPUB**。
- 封面域名受网站 `organizer_cover_hosts` 白名单约束（见 §8）。

## 3. 数据模型与工作区（workspace.py）

工作区目录：`%LOCALAPPDATA%\EbookOrganizer\workspace`（用户级）。

### 3.1 books 表（每本书一条）
- `book_id`：基于内容 SHA-256 的稳定 ID（`BK_` 前缀），重扫不重复。
- `metadata`：标题/作者/分类/版权等（见 §3.3）。
- `status`：`ok` / `failed` / `blocked` 等；`failed`/`blocked` 的书**不能上传**。
- `excluded`：布尔，被排除的书不参与上传。
- `locked`：已锁定的字段集合（编辑时合并）。
- `issues`：识别出的问题标记。

### 3.2 results 表（每次外部操作的结果）
按 `target` 区分：
- `r2` → `{"state":"verified", "url":"https://img.lmonly.com/.../cover.webp"}`
- `quark` → `{"state":"shared", "share_url":"https://pan.quark.cn/s/...", "extract_code":"..."}`
- `site:<site_id>`（如 `site:jingye-local`）→ `{"status":"ok", "resource_id":111}`

### 3.3 edit() 可编辑字段白名单（重要）
`workspace.edit()` 仅允许以下字段，写入其它字段会抛 `ValueError("包含不可编辑字段")`：

```
title, subtitle, author, translator, publisher, isbn, description,
main_category, subcategory, copyright_status, source_reference,
rights_review_status, classification_status, language, publish_year
```

> ⚠️ 注意：`classification_evidence`（分类证据说明）**不在白名单内**，流水线自动分类时只能写 `main_category / subcategory / classification_status`，不能写证据字段。

### 3.4 单实例锁
`workspace.root/organizer.lock`（`QLockFile`）。程序已在运行时，再次启动的新实例会退出（避免双开写库冲突）。

## 4. 全自动流水线（pipeline.py）——核心

`run_full_pipeline(ws, config, credentials, opts, control, progress)` 把分散的能力串成无人值守链路。

### 4.1 选项（opts）
| 选项 | 默认 | 说明 |
|---|---|---|
| `provider` | `quark` | 网盘：夸克 / 百度 |
| `dry_run` | `False` | 只统计，不写库不联网 |
| `force` | `False` | 忽略已完成标记，强制重做（补封面/改元数据用） |
| `auto_classify` | `True` | 关键词命中即自动确认分类 |
| `auto_rights` | `True` | 对未确认的书批量申报默认版权策略 |
| `rights_status` | `authorized` | 批量申报的版权状态 |
| `source_reference` | `自有/已购电子书资源` | 批量申报的来源说明 |
| `publish` | `False` | 同步时链接校验通过后自动发布 |
| `batch` | `20` | 网站每批提交本数（1–500） |
| `limit` | `0` | 限制处理前 N 本（冒烟用，0=全部） |
| `book_ids` | `""` | 逗号分隔的指定 book_id（只处理这些） |

### 4.2 五个阶段
1. **分类自动确认**：对 `classification_status != confirmed` 的书调 `engine.classify()`；有候选则写 `main_category` + `confirmed`；无候选进 `needs_classification` 队列。
2. **版权批量申报**：对未 `rights_review_status==confirmed` 或 `source_reference` 为空的书，写 `copyright_status` + `source_reference` + `rights_review_status=confirmed`；不申报的进 `needs_rights` 队列。
3. **封面上 R2**：对 `uploadable` 且有本地封面、且 `r2.state != verified` 的书调 `upload_cover()`。未配置 R2 则整段跳过（不报错）。
4. **传网盘**：`quark_connector()` 过环境闸门后，对 `quark` 无 `share_url` 的书调 `upload_book()`。闸门不过则记入错误并跳过。
5. **同步网站**：对已传网盘且网站未 `ok` 的书，分批 `SiteClient.preview()` → 构造 `choices` → `commit()`。

### 4.3 三个关键设计
- **断点续传**：每阶段都先查已有结果（verified / share_url / site ok），已完成自动跳过；`--force` 才重做。
- **闸门分流不中断**：未过「分类确认 + 版权确认 + 有来源」闸门的书不进 `uploadable`，记入队列，最后在摘要里列出，**不阻塞其余书**。
- **可暂停/取消**：每本之间 `control.check()`，桌面端「任务与异常」页可暂停/取消。

### 4.4 输出
`format_summary(summary)` 返回纯文本摘要（总数 / 各阶段成功·跳过·失败 / 错误首条）。

## 5. 连接器层（connections.py）

### 5.1 quark_connector() —— 含已修复的路径规范化
```python
def quark_connector(workspace, config):
    ...
    connector = QuarkCloudConnector(settings)
    # node 在 Windows 长路径前缀 \\?\ 下会 realpathSync 报错，需先规范化
    def _norm(p):
        return Path(str(p).replace("\\\\?\\", "").replace("//?/", ""))
    connector.cli = _norm(connector.cli)
    connector.node = _norm(connector.node)
    if not _detect_quark_agent(connector.cli, connector.node):
        raise ValueError("夸克官方连接器不认可当前运行环境。...")
    return connector
```
> 修复点：检测通过**后**仍要把 `connector.cli` / `connector.node` 替换为普通 Windows 路径，否则后续 `get_user_info()` / `upload()` 调用时 `cwd` 仍是 `\\?\` 长路径，node 内部 `realpathSync('C:')` 报错（即「CloudConnectorError」）。

### 5.2 upload_book()（夸克 / 百度）
- 前置闸门：`status` 非 failed/blocked、`rights_review_status==confirmed`、`source_reference`、`copyright_status`、`main_category`、`classification_status==confirmed`。
- 已 `share_url` 直接返回（断点续传）。
- 按 `main_category/subcategory` 在夸克父目录（`quark_parent`）下自动建分类文件夹（fid 缓存进 `quark_directories`）。
- 上传 → 分享（`--url-type 1 --expired-type 1`）。
- 结果存 `results` 表（`state=shared, share_url, extract_code`）。

### 5.3 upload_cover()（R2 封面上传）
- boto3 HEAD 探测 → PUT 上传 → GET 校验可达 → 存 `results[r2]={state:verified, url}`。
- 封面域名为工作区 `r2_public`（如 `https://img.lmonly.com/`）。

### 5.4 SiteClient（网站同步）
- `base = config.site_url`，要求 HTTPS（localhost HTTP 仅限本地测试）。
- 携带 `Bearer site_token`（来自凭据库）。
- `info()` 取 site_id 与分类列表；`preview(ids)` 取每本书建议动作；`commit(preview, choices, control, progress)` 提交创建/绑定/选择并可选发布。

## 7. 打包（Ebook.spec → dist/Ebook/Ebook.exe）

- 工具：PyInstaller，`Ebook.spec` 入口 `scripts/organizer_entry.py`。
- 命名：`name='Ebook'`（exe 与目录均 Ebook）。
- **ICU 排除修复**（关键）：
  ```python
  # Qt 6.11 使用 Windows 自带无版本后缀 ICU ABI。构建宿主的另一份 ICU 78
  # 同名 DLL 会误入包并遮蔽系统库，引发 QtWidgets 加载失败。
  a.binaries = [e for e in a.binaries
                if Path(e[0]).name.lower() != 'icuuc.dll'
                and not Path(e[0]).name.lower().startswith('icudt')]
  ```
  → 复用系统 `C:\Windows\System32` 的 ICU，**不打包 ICU DLL**。
- 产物结构：`dist/<某目录>/Ebook/Ebook.exe` + `_internal/`（依赖库）+ `使用说明.md` + `构建环境.lock`。
- 构建命令：
  ```bash
  .venv\Scripts\python.exe -m PyInstaller --noconfirm --workpath build/EbookX --distpath dist/EbookX Ebook.spec
  ```
  （注：旧 `build`/`dist` 目录被占用时需换新的 workpath/distpath，见 §9.4）

## 8. 配置与凭据

### 8.1 网站封面白名单（`.env`）
`D:\网盘拉新\.env`：
```
ORGANIZER_COVER_HOSTS=img.lmonly.com
```
`app` 端 `get_settings()` 缓存，改后需**重启网站**生效。空白名单时带封面的同步会被 `validate_package` 以「封面域名未获准」整体拒绝。

### 8.2 Windows 凭据库（keyring）
- `r2_key` / `r2_secret`：Cloudflare R2 访问密钥
- `site_token`：网站专用可撤销 token（**不能**写入工作区 settings，会被 `set_setting` 拦截）
- `baidu_token`：百度网盘令牌（用百度时）

### 8.3 工作区 settings
- `connections`：`{site_url, site_id, baidu_root, quark_cli, connector_runtime, r2_account, r2_bucket, r2_public, quark_parent}`
- `quark_parent`：夸克目标目录 fid（如「电子书分享」文件夹）
- `site_url` / `site_id`：同步站地址与编号（当前 `http://127.0.0.1:8001` / `jingye-local`）

### 9.2 当前仍存在的限制 / 待处理项
1. **约 421 本（763 本批次）待人工分类**：关键词未命中，进 `needs_classification`，不阻塞其余书自动跑完。
2. **94 本 status=failed/blocked**：含早期 R2 测试书 `BK_b35aa`（status=failed），不能上传，需你决定是否修复状态。
3. **3000 本未扫描进工作区**：当前工作区只有之前扫的 763 本；那 3000 本需先在「书库整理」指目录扫描（一次性，之后按哈希增量）。
4. **旧 Ebook.exe 残留进程**：`dist\Ebook` 下 21800/21572 两个僵尸进程 taskkill 杀不掉，占内存，建议重启电脑清理。

6. **自动发布依赖链接校验**：`publish=True` 时网站端 `choice.publish` 仅当链接校验通过才转 `published`，校验不过仍会建草稿。

## 10. 使用流程（实操）

1. **扫描**（首次）：「书库整理」→ 选 3000 本目录 → 扫描（一次性）。
2. **配置**：「连接与分类设置」→ 填 R2 / 夸克 parent fid / 网站 URL；点「检查夸克授权」应提示通过。
3. **预演**：「全自动流水线」→ 点「仅预演 (dry-run)」看统计，确认无报错。
4. **验收小批量**：设「本数限制」=20 → 「开始全自动流水线」，观察「任务与异常」。
5. **放开全量**：确认无误后限制改 0 跑全量；待分类/待版权书在摘要里列出，后续补。

## 11. 给二次修改者的提醒

- 改 `pipeline.py` / `connections.py` / `ui.py` 后必须 **重新打包** 才能反映到 `Ebook.exe`（源码直接 `python -m ebook_organizer` 可即时验证）。
- 任何 `workspace.edit()` 写入字段必须在 §3.3 白名单内，否则弹「包含不可编辑字段」。
- 夸克相关路径一律走普通 Windows 路径，不要在 `\\?\` 前缀下调用 node CLI。
- 网站侧白名单/配置变更要重启网站（8001 当前为独立 uvicorn，父进程 PID 见运行时 `netstat`/`tasklist`）。
